# Standalone

**Play** is a one-shot. **Loop** (with **BPM**, 40–240, default 140) repeats until you hit Play again. Plugin hosts hide Play / Loop / BPM and use MIDI, which is the grown-up way to do it in a DAW.

**Export WAV** (plugin and Standalone) writes one shot plus FX tail, 24-bit stereo, 44.1 or 48 kHz. With Loop on, the file is **2 bars** at that BPM.

**Norm** (default on) peak-normalizes to −0.1 dBTP. Turn it off to keep the raw render, peaks and all.

Drag the waveform onto a DAW or the desktop for the same WAV plus a `.k1xp`. The Tune knob is what Standalone Play, the waveform, and that export listen to.
