# EQ

Five-band parametric, used two ways: per selected layer (toolbar **EQ**), and as post EQ under the FX row on Effects. Same editor, same habits.

The spectrum is the live output after FX and EQ when you are on the post EQ. Drag a node for freq/gain, wheel for Q, double-click to reset a band.

**EQ** (left of the rail header) bypasses the whole EQ. **Reset** (right half of that header) restores all bands and EQ on/off to defaults.

If a band looks like it is plotting a coup, double-click it. Peace returns.
