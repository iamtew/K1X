# Patches

**Init Patch** in the title bar shows a factory preset as Single / Category / Name, or Multi / Category / Name Stack.

- **Single** is the voice.
- **Multi** turns slots on (click about 1 ms early, sub about 4 ms late, sweep under the beater — one recipe per category).

Click for Init / Save / Save As / Export / Import, a factory category, or your saved list. Chevrons step the factory bank, then any extra patches.

Your files live in `%AppData%\Stupid Audio\K1X\Patches` as `.k1xp`. Saving a factory name stores your copy there; delete that file to hear the factory sound again.

Click **K1X** plus the version in the top left for About and a GitHub update check.

Drag the window corner to scale (40%–150%). The scale is saved with the session, so you do not have to re-negotiate with the pixels every time.
