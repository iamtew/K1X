# Hello, thud

K1X is a kick one-shot. 909 is the default, with 808, 707, Tight, and Hard if you want a different personality without starting over.

MIDI note-on retriggers and sets the body pitch from the note (A4 = 440 Hz). The Tune knob is for Standalone Play, the waveform, and WAV export — so the knob and the MIDI note are not fighting each other.

This is the user book. Internals live under Spec, Architecture, and DSP notes in the sidebar, if you enjoy reading the wiring.

VST3 and standalone. Windows, Linux, and Mac.
