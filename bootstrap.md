# K1X - Kick Drum Creator

VST3 plugin build on JUCE (location C:\Users\Mikael\JUCE).
Has both VST3 version and Standalone version.
Uses Just, Justfile for building.
Required target "build-dist" which creates a dist directory and zip files with the releases.
Version is picked up from Git tag.
`TEW03` is a sister plugin, use as inspiration and reference: C:\Users\Mikael\src\TEW03

## K1X what it is:
- Blue, grey, orange colors of interface. Steel blue shades.
  - 1a2332 Blue
  - b7c5d6 Light Gray
  - 151515 Dark Gray
  - d94214 Orange
  - 000000 Black
  - FFFFFF White
- Kick drum based on the 909 classic drum.
- This can be adjusted and madce sounding better and cooler.
- Saturation, EQ, filters, etc. the plugin has a processing chain the user can use to tune the sound.
- Clean and organized interface.
- Waveform preview in a window.
- Default synced with BPM of DAW can can have limits set on length of kick, so user can make them fit 1/4, 1/8, 1/16 notes etc. easily.
- Standalone version has a play function to preview the kick and an export function so a single sample can be exported out to WAV. 
- Shows name and version in top left corner like `TEW03` does, when clicked about dialog and it will check Github for latest version, just like `TEW03`.
